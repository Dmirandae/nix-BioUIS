# Semana 2: Procesamiento de Texto con Herramientas Unix

## Objetivos
- Dominar el uso de `cut`, `sort`, `grep`, `sed`
- Aprender a manipular columnas y filtrar datos
- Introducción a `awk` para procesamiento de datos estructurados

## 2.1 Extracción de Columnas con `cut`

```bash
# Extraer columnas específicas
cut -f 1 archivo.txt           # Primera columna
cut -f 1,3 archivo.txt         # Columnas 1 y 3
cut -f 1-3 archivo.txt         # Columnas 1 a 3

# Cambiar delimitador (por defecto tab)
cut -d',' -f 1,2 archivo.csv   # CSV separado por comas
```

## 2.2 Ordenamiento con `sort`

```bash
# Ordenar por columna
sort -k 2 archivo.txt          # Ordenar por columna 2
sort -k 2 -n archivo.txt       # Orden numérico
sort -k 2 -r archivo.txt       # Orden inverso

# Ordenar uniendo archivos
sort -k 2 probe2gene.txt > tmp1
```

## 2.3 Búsqueda con `grep`

```bash
# Búsqueda simple
grep "patrón" archivo.txt

# Opciones útiles
grep -i "patrón"               # Insensible a mayúsculas
grep -v "patrón"               # Líneas que NO coinciden
grep -c "patrón"               # Contar coincidencias
grep -n "patrón"               # Mostrar números de línea
grep -w "patrón"               # Palabra completa
grep -f lista.txt              # Usar patrones desde archivo
```

## 2.4 `awk`: Procesamiento de Datos Estructurados

### Estructura básica de awk
```bash
awk 'condición {acción}' archivo.txt

# Variables especiales
awk '{print $1}' archivo.txt   # Primer campo
awk '{print $NF}' archivo.txt  # Último campo
awk '{print NF}' archivo.txt   # Número de campos
awk 'NR < 6' archivo.txt       # Primeras 5 líneas
awk 'NR > 1 && NR < 7' archivo.txt  # Registros 2-6
```

### Operaciones con awk
```bash
# Cálculos
awk 'BEGIN {print 2+3}'        # Imprimir resultado
awk '{s=0; for (i=2; i<=NF; i++) s=s+$i; print s}'  # Sumar columnas

# Filtrado
awk '/patrón/' archivo.txt     # Líneas que coinciden
awk '/patrón/ {print $1}'      # Imprimir campo específico

# Contadores
awk '/patrón/ {n++}; END {print n}'  # Contar coincidencias
```

## 2.5 `sed`: Edición de Texto en Línea de Comandos

```bash
# Sustitución de texto
sed 's/patrón/reemplazo/g' archivo.txt

# Eliminar líneas
sed '/patrón/d' archivo.txt

# Extraer partes específicas
sed -n 's/.*<PMID>\(.*\)<\/PMID>.*/\1/p' archivo.xml
```
