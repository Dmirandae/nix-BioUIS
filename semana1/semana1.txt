# Semana 1: Fundamentos de Línea de Comandos

## Objetivos
- Familiarizarse con el entorno de línea de comandos en Linux
- Aprender comandos básicos para navegación y manipulación de archivos
- Comprender la estructura de archivos de datos

## 1.1 Introducción al Shell

### ¿Qué es el shell?
El shell es una interfaz de línea de comandos que permite interactuar con el sistema operativo. Bash (Bourne Again SHell) es el shell más común en sistemas Linux.

### Comandos básicos
```bash
# Ver manual de un comando
man comando
man -help
comando --help

# Navegación y visualización
ls                          # Listar archivos
ls -lsh                     # Listar con detalles y tamaño
pwd                         # Mostrar directorio actual
cd                          # Cambiar directorio
cd ~                        # Ir al directorio home
cd -                        # Volver al directorio anterior

# Información del sistema
df -h                       # Espacio en disco
free                        # Memoria disponible
uname -a                    # Información del sistema
```

## 1.2 Trabajando con Archivos

### Creación y organización
```bash
# Crear directorios
mkdir nombre_directorio

# Copiar archivos
cp origen destino
cp -r directorio_origen directorio_destino

# Mover y renombrar
mv origen destino

# Eliminar archivos
rm archivo
rm -r directorio
```

### Visualización de contenido
```bash
# Ver primeras líneas
head -n 5 archivo.txt

# Ver últimas líneas
tail -n 5 archivo.txt

# Ver archivo completo con paginación
less archivo.txt

# Información del archivo
file archivo
stat archivo
```

## 1.3 Estructura de Datos

Los archivos de datos típicamente contienen información tabular. En el ejemplo, trabajaremos con un archivo que contiene:

- **4 columnas**: especie, id, longitud, ángulo
- **Ángulo**: corresponde al ángulo de la copa de un árbol particular
- **Distancia**: en metros desde el árbol hasta el observador

## 1.4 Redirección y Tuberías

```bash
# Redirigir salida a archivo
comando > archivo      # Sobrescribir
comando >> archivo     # Añadir al final

# Tuberías (pipes)
comando1 | comando2    # Pasar salida de comando1 a comando2

# Combinación de comandos
cat archivo | tr ',' ' ' | awk 'NR > 1 {print $0}'
```
